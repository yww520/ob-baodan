# 📖 全家保单管理系统 · 使用指引

欢迎来到您的本地保单管理与 AI 条款梳理中心！本系统针对电子保单管理设计，实现了**「本地精准隐私脱敏 ➔ Obsidian 动态看板 ➔ 大模型深度条款梳理」**的全流程闭环。

---

## 🗂️ 1. 目录架构一览

- **`00_看板中心/`**
  - `📊 保单全景看板.md`：基于 **Obsidian Kanban 插件**，支持按状态拖拽保单（保障中 / 等待期 / 满期 / 待缴费）。
  - `📅 年度缴费日历与预算.md`：基于 **Dataview 插件**，自动提取保费、交费日、保额汇总。
- **`01_保单库/`**：按险种（重疾、医疗、意外、寿险、年金）归档的保单 Markdown 笔记。
- **`02_原始保单_PDF/`**：存放您下载的各家保险公司官方电子保单 PDF。
- **`_system/`**：
  - `scripts/policy_processor.py`：保单脱敏与自动笔记生成引擎。
  - `policy_secret_mapping.json`：本地自动维护的隐私解敏映射字典（绝不上云）。

---

## 🚀 2. 如何添加一份新保单？

### 第一步：放入电子保单
将您下载的官方电子保单 PDF 文件（例如 `达尔文9号重疾险.pdf`），放入文件夹：
`/Users/clawbot/AI/baodan/baodan/02_原始保单_PDF/`

### 第二步：一键运行脱敏与解析脚本
在终端中执行以下命令（支持单份处理或批量处理）：

```bash
# 批量处理 02_原始保单_PDF 目录下的所有新保单
python3 /Users/clawbot/AI/baodan/baodan/_system/scripts/policy_processor.py --batch

# 或者单独处理某一份保单
python3 /Users/clawbot/AI/baodan/baodan/_system/scripts/policy_processor.py "/path/to/your_policy.pdf"
```

### 第三步：在 Obsidian 中查看与交互
1. 脚本会自动在 `01_保单库/` 下对应的分类目录中生成格式化笔记。
2. 笔记已在本地完成靶向脱敏：姓名、身份证、手机、银行卡、保单号全部替换为代号。
3. 打开 `00_看板中心/📊 保单全景看板.md`，把新生成的保单卡片拖入对应状态列表中。
4. 打开笔记，复制第二节中的 **Prompt 模板与脱敏条款**，粘贴发送给任意公网大模型（DeepSeek、ChatGPT、Claude），将分析出来的精炼赔付标准与暗坑直接粘回笔记！
